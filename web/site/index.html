KartPadNX Builder

Build Mario Kart Wii for your Switch from your own disc. The build runs on our PC, so yours doesn't have to be fast.

What you need

  • A Switch running homebrew (Atmosphère), with about 5 GB free on its SD card.
  • Your own Mario Kart Wii disc image: PAL (RMCP01), revision 0, as .iso, .wbfs or .rvz. NTSC (RMCE01), Japanese and Korean discs, and later PAL revisions don't work.
  • Time for the upload (a 4 GB image) and the download (about 6 GB).

Have a fast Windows PC? You can build on it instead with the PC builder; the result is the same.

Playing

    
Hold R while starting any game to open the Homebrew Menu, then start MKW Launcher. Start it this way, not from the Album: from the Album the Switch gives homebrew too little memory and the launcher shows a warning.

    
Pick Mario Kart Wii or Retro Rewind and press Play (or +). The other tabs: Mods, Saves (backups, made automatically before each start), Licenses (names, Miis, VR/BR), Miis (your Switch Miis, used by both games), Game Files and Settings (volume, FPS counter, widescreen, launcher updates).


    
When Retro Rewind updates

    
Build here again and copy the new zip's files over the old ones; your saves are kept. The builder always uses the newest Retro Rewind. Don't update Retro Rewind on the SD card by itself (with Wheel Wizard or a new RetroRewind6 folder): its code is built into the game, so a different version on the card won't match.


    
Mods

    
    
      
  1. Copy each mod's folder to /switch/kartpad/mods/ on the SD card. Inside, files are laid out like the disc (for example Race/Course/…), or it's a Riivolution pack with a riivolution folder.
    2. 
      
  2. In the launcher's Mods tab, pick the game and switch the mods on. Each game has its own list.
    3. 
    

    
Mods that replace files (textures, tracks, music) work without rebuilding. Mods that change the game's code (Kamek/Pulsar .pul code, Gecko codes) don't.


    
If something goes wrong

    
    
      
  • The site says the disc is the wrong version: it really is; only PAL revision 0 works.
    • 
      
  • The upload stopped: reload this page and pick the same file again; it carries on where it left off.
    • 
      
  • The builder is offline: it runs on the maintainer's PC; try again later.
    • 
      
  • "Low memory mode" in the launcher: start it by holding R on a game, not from the Album.
    • 
      
  • The game crashes: open an issue with /switch/kartpad/kartpad-runtime.log and the newest file in /atmosphere/crash_reports/ from your SD card, and say what you were doing.
    • 
    


    
Status

    
The base game and Retro Rewind are playable: menus, races, Grand Prix. Retro WFC online connects and races start but is still being tested. It runs below a locked 60 fps for now.
