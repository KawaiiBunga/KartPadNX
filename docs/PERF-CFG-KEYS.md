Generated by `python3 builder/list-config-keys.py --write`; do not edit by hand.

`sdmc:/switch/kartpad/perf.cfg` holds one `key value` per line (decimal or `0x` hex, `#`
comments) and is read once at startup. Without the file every key has its default.

- **opt**: an optimization switch. The runtime log shows each as `[opt] key=value (source)`.
  `opt_safe 1` turns every opt off except those the file sets explicitly.
- **setting**: a plain value.
- `profile tuned|legacy` (default `tuned`) selects the thread placement; `legacy` is the old
  placement, kept for A/B runs. Placement keys are documented at the top of
  `switch/src/perf_switch.cpp`.
